Instrukcja uruchomienia aplikacji backendowej:
  * pobrać plik picture-annotation-server.jar znajdujący się w repozytorium: https://github.com/filipwosko/pictures-annotator
  * uruchomić w lokalizacji pliku terminal i wpisać komendę: java -jar picture-annotation-server.jar.


Innym sposobem uruchomienia backendu jest sklonowanie całego repozytorium https://github.com/filipwosko/pictures-annotator. 
Otworzenie pobranego projektu poprzez Intellij IDEA i uruchomienie pliku PicturesAnnotatorApplication.java
